# Objetivos de la plataforma

## Problema a resolver

Las solicitudes de clientes llegan por distintos medios y se registran en una hoja compartida. Esto puede provocar registros incompletos o duplicados, dificultar el seguimiento de las cotizaciones y generar retrasos o correcciones.

## Objetivos

- Centralizar las solicitudes de clientes en un solo registro. Se medirá revisando cuántas solicitudes quedan registradas y cuántas aparecen duplicadas o se pierden.
- Guiar la captura de información con campos estandarizados. Se medirá comparando la cantidad de solicitudes incompletas antes y después de usar la plataforma.
- Permitir consultar el estado, responsable y fecha límite de cada cotización. Se medirá con el tiempo promedio de respuesta y el porcentaje de cotizaciones entregadas a tiempo.
- Facilitar que solicitudes similares se revisen y coticen de forma consistente. Se medirá comparando el porcentaje de cotizaciones que necesitan modificaciones con el proceso actual.
