Herramientas que usará el equipo y para qué sirve cada una: 


1. GitHub (Control de Versiones y Gestión): Centraliza el código fuente de la plataforma web, el historial de cambios, la revisión de código mediante Pull Requests y el seguimiento de tareas/issues para garantizar una colaboración en paralelo ordenada.

2. Node.js / React (Stack de Desarrollo Web): Entorno de ejecución y librería de interfaz de usuario para construir el dashboard web interactivo donde los clientes de Leavesales visualizan métricas, embudos de venta y análisis de rendimiento de sus canales de WhatsApp.

3. WhatsApp Business Platform API / Meta for Developers: API oficial utilizada para simular e integrar la transmisión de mensajes, sincronización de contactos, recepción de webhooks en tiempo real y automatización de flujos de conversación para las empresas clientes.

4. Postman (Pruebas de API): Permite diseñar, documentar y probar las solicitudes HTTP (GET, POST) dirigidas a la API de WhatsApp Business y a los endpoints del backend de la plataforma antes de integrarlos al frontend.

5. Visual Studio Code (IDE): Editor de código estándar utilizado por todo el equipo, configurado con extensiones de soporte para Git, ESLint y Prettier para mantener la consistencia en la sintaxis del código y facilitar el trabajo por ramas.
